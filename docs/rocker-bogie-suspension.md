## 구조 (NASA MER/MSL 방식)
- 차체 연결점 3개: 좌/우 로커 피벗(측면 레일, 하중 지지) + 차동 바 피벗(상부 중앙, Z축 회전)
- 로커: 전방 휠(F, 구동) + 보기 피벗(B) + 상방 암(U, 차동 링크 연결)
- 보기: 중간 휠(M) + 후방 휠(R) — V자 플레이트, 아이들러
- 차동: 바(896mm, Z축 회전) 양단 ↔ 로커 상방 암을 X 방향 링크 로드(150mm, 로드엔드)로 연결
- 차체 피치 = (좌 로커각 + 우 로커각)/2 (수평 "유지"가 아님)

## 설계 근거
- 로커 피벗 X = (x_F + 2·x_B)/3 → 3륜 등하중 (각 98 N @ 60 kg). 피벗을 뒤로 옮기면 전방 휠이 가벼워져 등반 유리
- 보기 피벗 = 중간·후방 휠 중점, 휠 축보다 75 높음
- 차동 링크는 X 방향 배치 필수 — Y 방향(바 반경 방향)이면 바 끝단 원호 운동으로 구속 과잉
- 차동 1:1 연동 오차 ±15° 범위에서 <0.5°
- 휠 Ø150(UWRF 최대)은 1000mm 프레임·과수원 지면에 과소 → 10인치(Ø250) 공압으로 변경
- 전방 구동 선택: 로커 직결 휠이라 하중이 항상 1/3로 안정. 20cm급 장애물 등반이 필요하면 후방 허브모터 추가(4WD)

## 부품
- 로커/보기: Al 6061-T6 12t 플레이트, 암 폭 60 (워터젯, DXF 포함)
- 로커 피벗: SHF16 플랜지형 샤프트 서포트(2홀 M5 @40, 레일 한 슬롯 체결) + SFJ16 축 + 6003ZZ ×2(로커 보스) + SCS16 세트 칼라
- 보기 피벗: SFJ12 + 6001ZZ ×2 / 차동 피벗: Ø12 핀 + 6001ZZ ×2
- 휠: 전방 10" BLDC 허브모터 36V 350W ×2 (M18 2S 36V 직결), 중간·후방 10" 3.00-4 공압 아이들러 ×4
- 링크: Ø8 로드 + 로드엔드(PHS8) ×2, 길이 조정식

## 미결 사항
- 프레임 상단 중앙 X=-150 ±120 구간은 차동 바 스윙 영역 — 배터리 배치 시 비워둘 것
- SHF16 단일 클램프 캔틸레버(SF 4.1). 하중 증가 시 X=0에 수직 HFS 멤버 추가 후 SHF16 2개 지지로 보강
- 허브모터 M12 축 → 로커 플레이트 드롭아웃 치수 모터 사양 확정 후 반영
- 상세 프레임 브라켓, 블레이드 데크와의 간섭은 별도 검토
