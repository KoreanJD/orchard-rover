## 개요
- **6축** (J1 요 Z / J2 어깨 Y / J3 팔꿈치 Y / J4 전완 롤 X / J5 손목 피치 Y / J6 툴 롤 X) — 협동로봇 표준 6R
- 리치 1,050 mm (J2 축 → ISO 플랜지), 가반 3 kg, 팁 속도 0.5 m/s (J2 ≤ 25~30°/s)
- 팔 자중 ≈ 15 kg, 36 V DC, CAN, IP54
- 툴: 집게 / 전동 가위(톱 대체, 모델 선정 보류 — 1순위 마끼다 DUP361 36V 33mm) / 예초기, ISO 9409-1-50-4-M6 + 수동 퀵체인저
- 베이스 마운트: 구동체 상단 레일 X=+300 (차동 바 스윙 영역 X=−150±120 회피), J2 축 Z=958
- 관절 한계: J1 ±180 / J2 −20~90 / **J3 ±120 (케이블 드럼 제약)** / J4 ±180 / J5 ±110 / J6 ±180

베이스→어깨 200 / 상완 500 (HFS5-3030 ×2 사다리, Z 60 간격 — 케이블 채널 겸용, 양단 링 하우징 회피로 X 85~415) / 전완 422 (J4 하우징 80 + Al 튜브 Ø50×2t) / 손목 128

## 손목
J4 하우징 Ø76×80 → 전완 튜브 Ø50×2t → J5 요크(뒷판 + 12t 양측, 길이 85) → 손목 블록 50×60×60 (J6, 카메라 마운트) → ISO 9409-1-50 플랜지 Ø63×8
- J4 하우징 보어: 모터 여유 Ø58 | 감속기 파일럿 Ø42 | 축 여유 Ø46 | 롤 베어링 6810 시트 Ø65. 출력 허브가 베어링 내륜을 관통, 감속기 출력축 Ø8 보어
- J5: +Y 감속기 출력면 ↔ 블록 Ø12 축, −Y 치크 6001 ↔ 블록 Ø12 축. 요크 뒷판은 J5 ±110° 에서 블록·카메라 회전 반경(≈56) 밖

## 가동 범위 간섭 (`motion_check.py`, 부품 단위 간섭 > 1 mm³)
J1 ±180 / J2 −20~90 / J3 ±120 / J4 ±180 / J5 ±110 / J6 ±180 단일 관절 스윕(10°, 171 자세) 충돌 없음.
조합 210 자세 중 30 충돌 — **모두 팔 ↔ 차체** (팔 자체 간섭 없음), 경로 계획에서 회피할 운용 제약:
- J2 = −20 에서 |J1| ≥ 135 (뒤쪽): 전완판·J4 하우징 ↔ 차동 포스트·바, J3 = −120 이면 J3 모터 ↔ 로커 플레이트
- J1 = ±90 (측면) 에서 J2 ≤ 0, J3 = −120: J4 하우징·전완 튜브 ↔ 프레임 상단 레일
- J2 = 0, J3 = −120 (전완을 아래로 접음): J5 모터(J4 = −90) 또는 ISO 플랜지(J5 ≈ ±90~110) ↔ 프레임
세부 목록은 `output/arm/motion_check.txt`

## 가스 스프링 밸런서 (J2)
압축형. 베이스 앵커 J2 축 **아래** 180 (터릿 상면 클레비스), 상완 앵커 팔 중심선 r=100 (측판 바깥면 스터드), 스프링은 상완 측판 바깥 평면 (팔 좌표 Y −76). 350 N, 길이 174~279, 스트로크 106 (−20°~+90°). 수평 보상 30.6 N·m, 잔류 49 → ×1.5 = 74 < 80 ✓ (400 N 검토)
- 앵커를 축 위에 두면 같은 압축 스프링이 팔을 누르고(수평 −30.6 N·m) 길이가 83 mm 까지 줄어 성립하지 않음

## MoveIt2 기술 패키지 (`urdf_export.py` → `output/urdf/orchard_rover_description/`)
- ROS 2 ament 패키지: `urdf/orchard_rover.urdf`, `srdf/orchard_rover.srdf`, `meshes/{visual,collision}/*.stl` (mm STL × 0.001)
- 링크: base_link(구동체 + J1 고정부) → j1_link → upper_arm → forearm_root → forearm_tube → wrist → flange → tool0
- 관절 축·부호는 CAD 자세 함수(`place`)와 동일: J1 +Z, J2·J3·J5 −Y (양수 = 들어 올림), J4·J6 +X. 원점 J2 축 = (0.300, 0, 0.958) m
- 한계 = 가동 범위 표, effort·velocity = 액추에이터 표. SRDF: arm 그룹(base_link→tool0), home·transport(T3) 자세, 인접 링크 충돌 제외
- 충돌 메시는 coarse (공차 3 mm). 관성은 CAD 체적 × Al 밀도 근사 (모터 실밀도 아님) — 동역학 제어용으로는 실측 보정 필요
- 가스 스프링은 2체 부품이라 미포함. 조합 자세의 팔↔차체 충돌 구간(가동 범위 절)은 base_link 충돌 메시로 MoveIt 이 회피
- 검증: URDF 순기구학으로 옮긴 부품 질량중심 = CAD 자세 (임의 6축 자세 3종, 0.01 mm 이내)
