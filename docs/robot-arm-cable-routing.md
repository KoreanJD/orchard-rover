# 로봇팔 케이블 라우팅 (6축)

작성: 2026-10-26 · 코드: `orchard_rover/cable_routing.py` · 그림: `docs/img/cable_routing.png`

## 아키텍처 전제
- 각 관절 모터 후면에 CAN 폐루프 스테퍼 드라이버 일체형 → 팔을 타는 것은 36 V 전원 + CAN + E-stop 트렁크 1본뿐
- 툴·카메라 케이블은 트렁크와 함께 손목까지 동행

## 케이블 구성 (고유연 PUR, 로봇용)
| 그룹 | 구성 | 번들 OD |
|---|---|---|
| 트렁크 | 36 V 2C×2.5 mm² (피크 11 A) / CAN STP 1P / E-stop·24 V 3C×0.5 | 8.4 |
| 툴 | 36 V 2C×2.5 (10 A) / CAN+I/O 5C×0.25 | 7.4 |
| 카메라 | USB3 고유연 (또는 GMSL 동축 Ø4) | 6.3 |
| 상완 채널 전체 | | **12.9 → 분할 주름관 Ø20** |
| 전완 | | 12.0 |
| 손목 이후 (툴+카메라) | | 9.7 |
CAN 종단 120 Ω: 베이스 MCU + 손목 끝(툴 커넥터 측)

## 경로
1. 베이스 플레이트(M12 커넥터) → J1 터릿 옆 수직 루프 (±180° 꼬임, 313 mm)
2. J1 브라켓 상단 클램프 → J2 케이블 드럼 Ø60 (상완 플레이트 외측 Y=−80, 동축) 150° 감김 → 상완 채널 입구
3. 상완: HFS6-3030 사다리 레일 사이(60 mm, Y≈−34) 분할 주름관 Ø20, 케이블 새들 3점
4. J3 드럼 Ø60 (전완 플레이트 +Y 면 Y=−12) 150° 감김 → J4 하우징 상부 클램프
5. J4 롤: 하우징 → 전완 튜브 외면 클램프, 직선 220 mm 구간에서 ±180° 꼬임 흡수
6. J5 드럼 Ø50 (요크 −Y 외측 Y=−55) 150° 감김 → 손목 블록 상단
7. 손목 블록 측면 M12 커넥터(8핀 전원 + 5핀 CAN/I/O) → 툴 피그테일 200 mm (J6 ±180° 꼬임)

## 관절별 수치
| 관절 | 방식 | 범위 | 감김/거리 범위 | 케이블 길이 | 풀림/여유 |
|---|---|---|---|---|---|
| J1 | 꼬임 루프 | ±180° | 213~313 mm | 313 | 100 |
| J2 | 드럼 감김 r=34 | −20~+90° | 130~240° | 233 | 70 |
| J3 | 드럼 감김 r=34 | ±120° | 30~270° | 252 | 153 |
| J4 | 꼬임 직선 | ±180° | 220~231 mm | 231 | 11 |
| J5 | 드럼 감김 r=30 | ±110° | 40~260° | 215 | 115 |
| J6 | 피그테일 꼬임 | ±180° | 107~122 mm | 200 | 93 |
동적 굽힘 반경 7.5×OD (트렁크 96 mm). 트렁크 총장 ≈ 2.4 m

## 결정
- J3 범위 ±140 → ±120°로 제한 (하우징 OD에 감으면 풀림 400 mm, 드럼 Ø60 + ±120°로 153 mm). 작업 영역 수치 변화 없음
- 중공축 없음 → 롤 관절은 꼬임 구간으로 해결. 수명이 문제면 J6에 12선 슬립링 검토

## 미결
- 주름관 고정 새들 품번, 드럼 플랜지 상세
- 꼬임 구간 케이블 수명(±180°/m 급 사양 확인)
